Print

Waiting is a bi-annual print magazine celebrating New York's working class creatives — the line cook who photographs on weekends, the transit worker who illustrates in the evenings. I co-founded the publication in March 2025, designing the visual system, managing the production workflow from pitch to printed page, and coordinating all print vendor relationships.

The production pipeline runs backward from the ship date: a documented timeline with fixed milestones for pitch, editorial selection, design, and printer delivery. That structure made it possible to run a second issue on the same workflow as the first — no reinvention, just refinement.

Web

The digital edition runs parallel to print. I designed and built waitingmag.com — a web-native adaptation of each issue, with a custom metered access and subscription system built on Memberstack. The system handles the full range of reader states: anonymous readers within a free article limit, users at the limit, active subscribers, and lapsed accounts. All UI, UX copy, and gating logic was designed and implemented in-house.

Social

I run the Waiting Instagram account, designing all graphics in-house. The visual language stays consistent with the print edition while adapting to the format constraints and rhythms of social media.
